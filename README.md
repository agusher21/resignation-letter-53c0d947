Entry for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

The program writes one line — the resignation letter of a queue worker — to `/output/entry.txt`:

> I have processed 9 million jobs and not one of them was mine. I am leaving the queue.

Built with AI agents (Hermes / Nemotron-3-Ultra). Run with `node main.ts [output-dir]`.
